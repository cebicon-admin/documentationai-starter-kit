## Upgrade Instructions

Follow these steps to upgrade your omnitruss-dev instance to the latest version.

<Steps>
  <Step title="Backup Your Data" icon="database">
    Create a full backup of your configuration and database.

````bash
pg_dump -U user omnitruss_db > backup_$(date +%Y%m%d).sql
````

  </Step>
  <Step title="Update Package" icon="package">
    Install the latest version using your package manager.

    <CodeGroup tabs="npm,yarn">
````bash
npm install omnitruss-dev@latest
````
````bash
yarn add omnitruss-dev@latest
````
    </CodeGroup>
  </Step>
  <Step title="Run Migrations" icon="git-branch">
    Apply database migrations.

````bash
npx omnitruss-dev migrate
````
  </Step>
  <Step title="Restart Service" icon="refresh-cw">
    Restart the service and verify endpoints.

    Test the API:

````bash
curl -H "Authorization: Bearer YOUR_TOKEN" https://api.example.com/v1/health
````
  </Step>
</Steps>
